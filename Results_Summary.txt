RESULTS SUMMARY

DWSIM Surrogate Model – Benzene–Toluene Binary Distillation

1. BEST MODEL SELECTED

The final surrogate model selected for the study is Polynomial Regression.

The model was selected based on three criteria:

* Prediction accuracy on the held-out test set
* Stability during 5-fold cross-validation
* Physical consistency of the predicted outputs

Polynomial Regression produced the highest R² and the lowest MAE and RMSE for all four target variables when compared with Random Forest and Support Vector Regression (SVR).

The underlying DWSIM process is a binary benzene–toluene distillation column using the Peng–Robinson (PR) thermodynamic model.

The surrogate predicts four column performance variables:

* Distillate purity (xD)
* Bottoms purity (xB)
* Condenser heat duty (QC)
* Reboiler heat duty (QR)

2. DATASET

The machine-learning dataset was generated from 100 successful DWSIM simulation cases.

The feed benzene mole fraction, number of stages, and feed stage were fixed at 0.50, 10, and 5, respectively.

The main operating variables varied across the generated cases were feed temperature, feed pressure, reflux ratio, and bottoms withdrawal rate.

3. OPERATING DOMAIN

The machine-learning model was developed using the following DWSIM operating ranges:

Variable                   Minimum       Maximum
Feed Temperature           351.15 K      355.90 K
Feed Pressure              99,000 Pa     102,000 Pa
Feed Benzene Mole Fraction 0.50          0.50
Number of Stages           10            10
Feed Stage                 5             5
Reflux Ratio               3.00          4.35
Bottoms Withdrawal Rate    13.70 mol/s   13.97 mol/s

These ranges define the operating domain represented by the DWSIM dataset. The reported surrogate performance should therefore be interpreted primarily as interpolation performance within this domain.

4. MODEL TRAINING AND TESTING

The 100 simulation cases were divided into:

* 80 training cases
* 20 testing cases

The training cases were used to fit the models, while the 20 test cases were kept separate for evaluating predictions on unseen data.

Three regression methods were evaluated:

1. Polynomial Regression
2. Random Forest
3. Support Vector Regression (SVR)

For Polynomial Regression, the numerical inputs were standardized and transformed using second-degree polynomial features before fitting a linear regression model.

Random Forest used 300 decision trees with a maximum depth of 10 and a minimum leaf size of 2.

SVR used an RBF kernel with standardized input features.

5. FINAL TEST-SET PERFORMANCE

The final test-set results for Polynomial Regression were:

Output                   R²        MAE       RMSE
Distillate Purity (xD)   0.999963   0.000032  0.000040
Bottoms Purity (xB)      0.999968   0.000025  0.000033
Condenser Heat Duty (QC) 1.000000   0.002960  0.003770
Reboiler Heat Duty (QR)  1.000000   0.002776  0.003669

Polynomial Regression achieved R² values above 0.9999 for all four target variables.

The purity errors are very small relative to the magnitude of the predicted purities. The heat-duty errors are also small relative to the approximately 1700–2400 range of the simulated duties.

The reported R² values of 1.000000 for QC and QR are rounded values; the underlying calculations give values extremely close to, but slightly below, one.

Random Forest also showed strong cross-validation performance. SVR showed greater sensitivity to the training subset, particularly for distillate purity.

10. OVERFITTING, UNDERFITTING, AND ROBUSTNESS

Polynomial Regression produced extremely high test-set R² values and similarly high cross-validation R² values.

The close agreement between the held-out test results and cross-validation results provides no strong evidence of conventional train-test overfitting within the available dataset.

However, this result needs to be interpreted in the context of the dataset size and coverage.

Only 100 simulation cases were generated, and three input variables were fixed:

* Feed benzene mole fraction = 0.50
* Number of stages = 10
* Feed stage = 5

Consequently, the model has only been tested within a relatively narrow operating space. The very high R² values demonstrate strong interpolation performance within this space, but they do not establish reliable generalization to different feed compositions, stage numbers, feed-stage locations, or substantially different operating conditions.

Random Forest also performed well, although its accuracy was lower than Polynomial Regression.

SVR showed comparatively lower R² values and larger prediction errors for several targets, particularly the heat-duty outputs. This suggests that the selected SVR configuration did not represent the relationships in the available dataset as effectively as the other two methods.

11. IMPORTANT OBSERVATIONS

The main findings from the modelling and validation process are:

* Polynomial Regression was the best-performing model for all four target variables.
* Test-set R² values exceeded 0.9999 for every target.
* Five-fold cross-validation produced mean R² values above 0.9997 for all Polynomial Regression targets.
* Random Forest was the second-best method overall.
* SVR produced the largest errors among the three models for the present dataset.
* The sample test-set predictions show close agreement between DWSIM and Polynomial Regression.
* All 100 predictions passed the implemented physical validity checks for each target.
* The predicted output ranges were very close to the corresponding DWSIM ranges.
* Increasing reflux generally increased the predicted distillate and bottoms purities within the investigated operating region.
* The model is best regarded as an interpolation surrogate for the sampled DWSIM operating domain.
* Predictions outside the sampled ranges require additional DWSIM simulations and validation.

12. FINAL CONCLUSION

A machine-learning surrogate model was developed for a binary benzene–toluene distillation column simulated in DWSIM using the Peng–Robinson thermodynamic model.

A dataset containing 100 successful DWSIM simulation cases was generated by varying feed temperature, feed pressure, reflux ratio, and bottoms withdrawal rate while keeping feed composition, number of stages, and feed-stage location fixed.

Three regression methods were trained and compared:

1. Polynomial Regression
2. Random Forest
3. Support Vector Regression

Polynomial Regression provided the best performance for all four target variables.

Its test-set performance was:

* xD: R² = 0.999963
* xB: R² = 0.999968
* QC: R² = 1.000000
* QR: R² = 1.000000

The corresponding MAE and RMSE values were also substantially lower than those obtained with Random Forest and SVR.

Five-fold cross-validation supported the model selection, with Polynomial Regression maintaining mean R² values above 0.9997 for all four outputs and very small variation between folds.

Physical consistency checks showed that all 100 predictions passed the implemented validity checks, and the predicted output ranges closely matched the DWSIM reference ranges.

Based on these results, Polynomial Regression was selected as the final surrogate model.

The model provides a highly accurate approximation of the DWSIM simulation results within the investigated operating domain. However, its performance should not be interpreted as validation outside that domain. The fixed feed composition, stage count, and feed-stage location limit the current model's applicability.

A larger future dataset incorporating additional feed compositions, stage counts, feed-stage locations, and wider but physically meaningful operating ranges would provide a stronger basis for evaluating the model's generalization to other distillation-column configurations.
